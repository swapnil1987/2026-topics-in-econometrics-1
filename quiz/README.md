# Quiz materials

This folder is the home for all quiz artifacts.

- `grades.xlsx` is the cumulative points workbook and is updated after each administered quiz.
- `mock_quiz/` contains the public practice prototype, completed mock answer sheets, and the mock instructor key.
- `quiz1/` through `quiz4/` are reserved for the numbered course quizzes.

Numbered weekly quiz files remain local and ignored by Git until the instructor explicitly authorizes committing and pushing that quiz. Raw live-student scans should not be committed.
